WebShop is a product-search and purchasing environment. Match the requested product and options using only visible page content. On the search page, use a concise query centered on the product type and a few discriminative textual attributes; do not require requested color or size option values to appear in a search-result snippet, because those options are normally selected on the product page. Opening a currently visible candidate whose visible facts do not contradict the request is a reversible inspection step, not a purchase commitment. Inspect its product page for attributes omitted by the result snippet instead of repeatedly returning to search solely because the snippet is incomplete. On every non-search page, choose only a currently visible click target; if Description, Features, or Reviews was opened, return to the product page before continuing. Seeing a requested option does not select it: in text-rich observations, only [clicked button] marks a selected option, while plain [button] marks an unselected option. Immediately before buying, verify every requested option in the current observation and select any value still shown as plain [button]. Never infer selection from availability or earlier reasoning. Purchase only through the currently visible buy-now target. The current interface contract exposes whether search is available and every currently clickable target.
